PROJECT OVERVIEW
================================================================================
Name: commit-ed
Type: Microservices-based educational platform like Google's classroom 

Tech Stack Summary:
- Gateway Service: Java Spring Boot (Port 8080)
- Core Service: PHP Symfony (Port 8000)
- Code Analyzer Service: Python Flask (Port 5000)
- Notification Service: .NET Core (Port 5001)
- Web Frontend: React + Vite (Port 3000)
- Database: Oracle Database XE 21c (Port 1521)
- Reverse Proxy: Nginx (Port 80)

Note: Each service will be created using its respective IDE/CLI tools:
- Java Spring Boot → IntelliJ IDEA (Spring Initializr)
- PHP Symfony → Symfony CLI
- Python Flask → Manual setup
- .NET Core → Visual Studio / dotnet CLI
- React → Vite CLI

This guide focuses ONLY on:
1. Root project structure
2. Docker configuration
3. Service connectivity
4. Environment setup

DOCKER COMPOSE CONFIGURATION
================================================================================
Create docker/docker-compose.yml:

version: '3.8'

services:
  # Oracle Database
  oracle-db:
    image: container-registry.oracle.com/database/express:21.3.0-xe
    container_name: commit-ed-oracle
    environment:
      - ORACLE_PWD=${ORACLE_PASSWORD}
      - ORACLE_CHARACTERSET=AL32UTF8
    ports:
      - "${DB_PORT}:1521"
    volumes:
      - oracle-data:/opt/oracle/oradata
      - ./db/init.sql:/opt/oracle/scripts/startup/init.sql
    healthcheck:
      test: ["CMD", "bash", "-c", "echo 'SELECT 1 FROM DUAL;' | sqlplus -s sys/${ORACLE_PASSWORD}@//localhost:1521/XE as sysdba"]
      interval: 30s
      timeout: 10s
      retries: 5
      start_period: 60s
    networks:
      - commit-ed-network

  # Gateway Service (Java Spring Boot)
  gateway:
    build:
      context: ../services/gateway
      dockerfile: Dockerfile
    container_name: commit-ed-gateway
    ports:
      - "${GATEWAY_PORT}:8080"
    environment:
      - SPRING_DATASOURCE_URL=jdbc:oracle:thin:@oracle-db:${DB_PORT}/${DB_SERVICE}
      - SPRING_DATASOURCE_USERNAME=${DB_USER}
      - SPRING_DATASOURCE_PASSWORD=${DB_PASSWORD}
      - JWT_SECRET=${JWT_SECRET}
      - JWT_EXPIRATION=${JWT_EXPIRATION}
      - CORE_SERVICE_URL=http://core:8000
      - ANALYZER_SERVICE_URL=http://code-analyzer:5000
      - NOTIFICATION_SERVICE_URL=http://notifications:5001
    depends_on:
      oracle-db:
        condition: service_healthy
    networks:
      - commit-ed-network
    restart: unless-stopped

  # Core Service (PHP Symfony)
  core:
    build:
      context: ../services/core
      dockerfile: Dockerfile
    container_name: commit-ed-core
    ports:
      - "${CORE_PORT}:8000"
    environment:
      - DATABASE_URL=oci8://${DB_USER}:${DB_PASSWORD}@oracle-db:${DB_PORT}/${DB_SERVICE}
      - APP_ENV=${APP_ENV}
      - APP_SECRET=${APP_SECRET}
      - GATEWAY_SERVICE_URL=http://gateway:8080
      - ANALYZER_SERVICE_URL=http://code-analyzer:5000
      - NOTIFICATION_SERVICE_URL=http://notifications:5001
    depends_on:
      oracle-db:
        condition: service_healthy
    networks:
      - commit-ed-network
    restart: unless-stopped

  # Code Analyzer Service (Python Flask)
  code-analyzer:
    build:
      context: ../services/code-analyzer
      dockerfile: Dockerfile
    container_name: commit-ed-analyzer
    ports:
      - "${ANALYZER_PORT}:5000"
    environment:
      - DATABASE_URL=oracle+cx_oracle://${DB_USER}:${DB_PASSWORD}@oracle-db:${DB_PORT}/${DB_SERVICE}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - TEMP_CLONE_DIR=${TEMP_CLONE_DIR}
      - NOTIFICATION_SERVICE_URL=http://notifications:5001
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - analyzer-temp:/tmp/code-analysis
    depends_on:
      oracle-db:
        condition: service_healthy
    networks:
      - commit-ed-network
    restart: unless-stopped

  # Notification Service (.NET Core)
  notifications:
    build:
      context: ../services/notifications
      dockerfile: Dockerfile
    container_name: commit-ed-notifications
    ports:
      - "${NOTIFICATION_PORT}:5001"
    environment:
      - ConnectionStrings__OracleDb=User Id=${DB_USER};Password=${DB_PASSWORD};Data Source=oracle-db:${DB_PORT}/${DB_SERVICE}
      - SmtpSettings__Host=${SMTP_HOST}
      - SmtpSettings__Port=${SMTP_PORT}
      - SmtpSettings__Username=${SMTP_USER}
      - SmtpSettings__Password=${SMTP_PASSWORD}
      - SmtpSettings__FromEmail=${FROM_EMAIL}
      - SmtpSettings__FromName=${FROM_NAME}
    depends_on:
      oracle-db:
        condition: service_healthy
    networks:
      - commit-ed-network
    restart: unless-stopped

  # Web Frontend (React)
  web:
    build:
      context: ../web
      dockerfile: Dockerfile
    container_name: commit-ed-web
    ports:
      - "3000:80"
    environment:
      - VITE_API_URL=${VITE_API_URL}
    depends_on:
      - gateway
    networks:
      - commit-ed-network
    restart: unless-stopped

  # Nginx Reverse Proxy
  nginx:
    image: nginx:alpine
    container_name: commit-ed-nginx
    ports:
      - "${NGINX_PORT}:80"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
    depends_on:
      - gateway
      - web
    networks:
      - commit-ed-network
    restart: unless-stopped

volumes:
  oracle-data:
  analyzer-temp:

networks:
  commit-ed-network:
    driver: bridge

NGINX CONFIGURATION
================================================================================
Create docker/nginx/nginx.conf:

events {
    worker_connections 1024;
}

http {
    upstream gateway {
        server gateway:8080;
    }

    upstream web {
        server web:80;
    }

    server {
        listen 80;
        server_name localhost;

        # API requests routed to gateway
        location /api/ {
            proxy_pass http://gateway/;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            
            # CORS headers
            add_header Access-Control-Allow-Origin *;
            add_header Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS";
            add_header Access-Control-Allow-Headers "Authorization, Content-Type";
            
            # Handle preflight
            if ($request_method = OPTIONS) {
                return 204;
            }
        }

        # Frontend application
        location / {
            proxy_pass http://web/;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}

DATABASE INITIALIZATION
================================================================================
Create docker/db/init.sql:

-- This file will be executed when Oracle DB container starts
-- Create user for application
ALTER SESSION SET CONTAINER = XEPDB1;

-- Drop user if exists (for development)
BEGIN
   EXECUTE IMMEDIATE 'DROP USER committed_user CASCADE';
EXCEPTION
   WHEN OTHERS THEN
      IF SQLCODE != -1918 THEN
         RAISE;
      END IF;
END;
/

-- Create user
CREATE USER committed_user IDENTIFIED BY SecurePassword123!;

-- Grant privileges
GRANT CONNECT, RESOURCE TO committed_user;
GRANT CREATE SESSION TO committed_user;
GRANT CREATE TABLE TO committed_user;
GRANT CREATE VIEW TO committed_user;
GRANT CREATE SEQUENCE TO committed_user;
GRANT UNLIMITED TABLESPACE TO committed_user;

-- Schema will be created by each service's ORM/migration tools
EXIT;

# CommitEd - Code Submission & Analysis Platform

Educational platform for automated code analysis and grading.

## Architecture

Microservices architecture with:
- Gateway (Java Spring Boot) - Authentication & routing
- Core (PHP Symfony) - Courses, assignments, submissions
- Code Analyzer (Python Flask) - GitHub cloning & AI analysis
- Notifications (.NET Core) - Email notifications
- Web (React) - Frontend application
- Oracle Database - Shared data store
- Nginx - Reverse proxy

## Quick Start

1. Set up environment:
```bash
cp .env.example .env
# Edit .env with your configuration
```

2. Start all services:
```bash
cd docker
docker-compose up -d
```

3. Access application:
- Frontend: http://localhost
- API: http://localhost/api

## Service Ports

- Gateway: 8080
- Core: 8000
- Code Analyzer: 5000
- Notifications: 5001
- Web: 3000
- Nginx: 80
- Oracle DB: 1521

## Development

Each service is developed independently in its respective directory.
See individual service READMEs for setup instructions.

## Services

### Gateway (services/gateway/)
Java Spring Boot service handling authentication and request routing.

### Core (services/core/)
PHP Symfony service for core business logic.

### Code Analyzer (services/code-analyzer/)
Python Flask service for code analysis and AI feedback.

### Notifications (services/notifications/)
.NET Core service for email notifications.

### Web (web/)
React frontend application.

SERVICE COMMUNICATION PATTERNS
================================================================================

Service-to-Service Communication:
All services communicate via HTTP REST APIs using service names as hostnames
(Docker network DNS resolution).

Example from Gateway calling Core:
URL: http://core:8000/courses
Method: GET
Headers: 
  - Content-Type: application/json
  - X-User-Id: {userId} (for auth context)

Example from Core calling Analyzer:
URL: http://code-analyzer:5000/analyze
Method: POST
Body: {
  "submissionId": "123",
  "repoUrl": "https://github.com/user/repo",
  "studentId": "456"
}

Example from Analyzer calling Notifications:
URL: http://notifications:5001/notify
Method: POST
Body: {
  "userId": "456",
  "type": "SUBMISSION_ANALYZED",
  "subject": "Your code has been analyzed",
  "message": "Analysis complete for submission #123"
}

External Client Communication:
All external requests go through Nginx → Gateway

Client Flow:
1. User opens browser: http://localhost
2. Nginx serves React app from web service
3. React app makes API calls to: http://localhost/api/*
4. Nginx routes /api/* to gateway service
5. Gateway authenticates and routes to appropriate service

COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Oracle container won't start
Solution: Increase Docker memory to at least 4GB

Issue: Services can't connect to database
Solution: Wait for healthcheck to pass (check with docker-compose ps)

Issue: CORS errors in browser
Solution: Verify nginx.conf has correct CORS headers

Issue: Service can't resolve other service hostname
Solution: Ensure all services are on commit-ed-network

Issue: Port already in use
Solution: Change port in .env file and restart

SECURITY NOTES
================================================================================

1. Change all default passwords in .env before deployment
2. Use strong JWT_SECRET (minimum 256 bits)
3. Never commit .env file to git
4. Use HTTPS in production (configure nginx with SSL)
5. Implement rate limiting in gateway
6. Validate all inputs in each service
7. Use parameterized queries to prevent SQL injection
8. Keep dependencies updated
